# Smart Dustbin Project Plan

## Project Objective

Develop an embedded smart dustbin capable of:

1. Detecting a nearby hand/object.
2. Automatically opening the lid.
3. Automatically closing the lid.
4. Measuring waste level.
5. Calculating approximate fill percentage.
6. Activating an alert when the bin is critically full.

## Controller

Arduino UNO

## Sensors

- HC-SR04 for hand/object detection
- HC-SR04 for waste-level detection

## Actuator

SG90 Servo Motor

## Indicators

- Green LED
- Red LED
- Buzzer

## Simulation Platform

Wokwi

## Development Strategy

The project will be developed incrementally through independent phases.
