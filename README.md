# Smart Dustbin – Industry-Oriented Embedded System

## Project Status

Phase 1 – Development Environment Setup

## Overview

This project is an industry-oriented embedded systems project that implements a smart dustbin with:

- Automatic lid control
- Hand/object detection
- Waste-level monitoring
- Full-bin alert
- LED status indication
- Buzzer alert

## Target Hardware

- Arduino UNO
- HC-SR04 ultrasonic sensors
- SG90 servo motor
- LEDs
- Buzzer

## Simulation

The project will be simulated using Wokwi.
